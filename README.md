# Movie-Ticket-Booking-System
A menu-driven Movie Ticket Booking System developed in C++.

## Features
1. List all movies currently playing 
2. For a chosen movie, list its shows (screen + start time) 
3. For a chosen show, display the seat layout with AVAILABLE / BOOKED status 
4. Book one or more seats for a show (reject an already-booked seat) 
5. Price the booking by seat type: SILVER ₹150, GOLD ₹250, PLATINUM ₹400 
6. Pay by UPI, Card or Cash — a failed payment must NOT confirm the booking 
7. Print a ticket: booking id, movie, screen, time, seat numbers, total amount 
8. Cancel a booking — the seats become AVAILABLE again
9.
